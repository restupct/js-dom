Manipulasi Lanjut • Hari 4 dari 4

Berinteraksi lebih dalam dari sekadar 'Klik'.

Pengguna web tidak hanya mengeklik tombol. Mereka mengetik, menekan Enter, memilih dropdown, dan menggeser mouse. Hari ini kita akan menyadap semua aktivitas tersebut secara real-time.

Tujuan pembelajaran

  1. Mendeteksi ketikan langsung menggunakan event input dan change.
  2. Mengenali tombol yang ditekan (seperti Enter atau Escape) menggunakan event keydown.
  3. Membuat efek hover kustom dengan mouseenter dan mouseleave.
  4. Membaca objek event (e.target dan e.key) untuk mendapatkan data spesifik.

1. Event input & change (Real-time)

Kalau kamu ingin memvalidasi form sebelum tombol simpan diklik (misalnya menghitung sisa karakter atau mengecek format email), gunakan event "input".

const formInput = document.querySelector("#username");

formInput.addEventListener("input", function(e) {
  // e.target.value adalah cara cepat mengambil isi ketikan
  // dari elemen yang sedang memicu event ini.
  console.log("Kamu mengetik: " + e.target.value);
});

Untuk elemen seperti <select> (dropdown) atau <input type="radio">, kita biasanya memakai event "change" yang baru menyala setelah pengguna selesai memilih opsi.

2. Event keydown (Mendeteksi Keyboard)

Bagaimana caranya agar saat di kolom chat, kita cukup menekan Enter tanpa repot mengeklik tombol Kirim? Gunakan keydown dan baca properti e.key.

const kolomChat = document.querySelector("#chat");

kolomChat.addEventListener("keydown", function(e) {
  if (e.key === "Enter") {
    console.log("Pesan dikirim: " + e.target.value);
    e.target.value = ""; // kosongkan setelah dikirim
  }
});

3. Event mouseenter & mouseleave (Hover JS)

Di CSS, kamu mengenal pseudo-class :hover untuk mengubah warna. Di JavaScript, kamu bisa menggunakan mouseenter (saat mouse masuk) dan mouseleave (saat mouse keluar) untuk menjalankan logika kompleks, seperti memunculkan kotak tooltip, menjeda slider, atau memanggil data dari server.

const kartu = document.querySelector(".kartu");

kartu.addEventListener("mouseenter", function() {
  console.log("Kursor masuk ke area kartu!");
});

kartu.addEventListener("mouseleave", function() {
  console.log("Kursor pergi dari area kartu!");
});

Praktikum

Tiga latihan ini dirancang untuk membiasakanmu dengan event baru. Mesin pemeriksa akan secara otomatis mengetik dan menggerakkan mouse ke elemenmu.

Tugas

Gabungkan materi ini untuk membuat fitur validasi real-time dan efek interaktif.
