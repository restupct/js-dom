Persiapan membuat halaman interaktif.

Sebelum membuat tombol yang bisa diklik, kamu harus tahu cara mengambil data dari pengguna, mengubah bentuk elemen (seperti gambar), dan memunculkan elemen baru ke halaman secara dinamis.

Tujuan pembelajaran

  1. Mengambil isian dari input form menggunakan value (bukan textContent).
  2. Memanipulasi atribut elemen, seperti mengubah gambar (src) dan menonaktifkan tombol (disabled).
  3. Membuat elemen HTML baru dengan document.createElement dan append.
  4. Membuang elemen dari halaman menggunakan remove.

1. Form itu berbeda: Gunakan .value

Pada Modul 1, kamu mengubah tulisan dengan textContent. Namun, untuk elemen form (seperti <input> atau <textarea>), teks yang diketik pengguna tidak disimpan di textContent, melainkan di value. 

const inputNama = document.querySelector("#nama");

// Membaca apa yang diketik pengguna
console.log(inputNama.value);

// Mengosongkan form kembali setelah data diambil
inputNama.value = "";
Ingat Aturan Ini!Tag pembungkus seperti <p>, <h1>, <div> menggunakan textContent. Tag form tunggal seperti <input> menggunakan value.

2. Mengubah Atribut (src, href, disabled)

Kamu tidak hanya bisa mengubah kelas (CSS) dan teks. Bagian-bagian dari tag (atribut) juga bisa dikendalikan oleh JavaScript. Ini sangat berguna untuk membuat fitur dinamis.

const foto = document.querySelector("#profilImg");
const tombol = document.querySelector("#btnKirim");

// Mengganti gambar
foto.src = "gambar-baru.jpg";

// Menonaktifkan tombol (agar tidak bisa diklik)
tombol.disabled = true;

3. Tiga Langkah Membuat Elemen Baru

Bagaimana jika datanya belum ada di HTML? Misalnya kamu ingin membuat "To-Do List" di mana itemnya bertambah terus. Kamu harus merakit elemennya secara manual. Selalu ada 3 langkah:

// 1. BUAT BENTUKNYA (Tag HTML-nya apa?)
const elemenBaru = document.createElement("li");

// 2. DANDANI ISINYA (Teks atau kelasnya apa?)
elemenBaru.textContent = "Belajar Event Listener";
elemenBaru.classList.add("tugas-penting");

// 3. TARUH DI HALAMAN (Mau dimasukkan ke dalam mana?)
const daftar = document.querySelector("#daftarTugas");
daftar.append(elemenBaru);

Perintah append() akan menaruh elemen barumu di urutan paling bawah (terakhir) di dalam elemen induknya.

4. Menghapus Elemen

Jika ada elemen yang tidak dibutuhkan lagi (misalnya menghapus pesan peringatan atau menghapus item keranjang belanja), gunakan perintah remove().

const notifikasi = document.querySelector(".alert");

// Hapus elemen tersebut sampai hilang dari HTML
notifikasi.remove();

Praktikum

Tiga latihan dasar untuk membiasakanmu dengan perintah baru ini. Pemeriksaan berjalan otomatis — tidak perlu screenshot.
