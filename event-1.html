Menghidupkan halaman dengan aksi pengguna.

Halamanmu sudah bisa diubah oleh JavaScript. Sekarang, kita akan menentukan kapan perubahan itu terjadi. Di sinilah Event Listener berperan untuk mendengarkan setiap ketikan, klik, atau pergerakan dari pengguna.

Tujuan pembelajaran

  1. Memahami konsep event (kejadian) pada JavaScript.
  2. Menggunakan addEventListener untuk menjalankan fungsi saat tombol diklik.
  3. Menggunakan e.preventDefault() untuk mencegah form me-refresh halaman.
  4. Menggabungkan materi Modul 1 dan 1b ke dalam sebuah blok Event Listener.

1. Apa itu Event Listener?

Event Listener ibarat seorang "penjaga" yang kamu tugaskan untuk mengawasi sebuah elemen HTML. Kamu memberinya dua perintah: "Tunggu sampai kejadian X terjadi, lalu lakukan tugas Y."

const tombol = document.querySelector("#btnSapa");

tombol.addEventListener("click", function() {
  // Semua kode di dalam blok ini HANYA akan berjalan 
  // SETELAH tombol tersebut diklik oleh pengguna.
  console.log("Halo!");
});
Kesalahan Fatal PemulaJangan pernah memanggil nama fungsi dengan tanda kurung di dalam addEventListener seperti ini:

tombol.addEventListener("click", sapaPengguna()); ❌

Itu akan membuat fungsinya langsung berjalan saat halaman dimuat, bukan menunggu diklik. Tulis format function kosong function() { ... } seperti contoh pertama.

2. Menghentikan Refresh Otomatis (Prevent Default)

Secara bawaan (default), jika kamu menaruh elemen <button> di dalam sebuah <form>, browser akan menganggapnya sebagai tombol Submit yang akan me-refresh (memuat ulang) seluruh halaman. Jika halaman me-refresh, seluruh modifikasi JavaScript yang kamu buat akan hilang dan kembali ke awal.

Solusinya adalah mencegat aksi bawaan tersebut dengan objek event (biasa disingkat e): 

const form = document.querySelector("#formTugas");

// Perhatikan huruf "e" di dalam kurung function
form.addEventListener("submit", function(e) {
  
  // Baris ajaib ini menghentikan refresh halaman
  e.preventDefault(); 
  
  console.log("Form disubmit, halaman aman!");
});

3. Merangkai Semuanya Menjadi Satu

Di Modul 1b, kamu sudah belajar mengambil isi form dan membuat tag baru. Sekarang, kita cukup memindahkan kode tersebut ke dalam Event Listener, sehingga aplikasi seperti "To-Do List" akan bekerja dengan utuh.

const btnTambah = document.querySelector("#btn");
const inputData = document.querySelector("#input");
const daftar = document.querySelector("#list");

btnTambah.addEventListener("click", function() {
  // 1. Ambil ketikan (Materi Modul 1b)
  const namaTugas = inputData.value;
  
  // 2. Bikin tag baru (Materi Modul 1b)
  const tagBaru = document.createElement("li");
  tagBaru.textContent = namaTugas; // (Materi Modul 1)
  
  // 3. Masukkan ke layar (Materi Modul 1b)
  daftar.append(tagBaru);
  
  // 4. Kosongkan kembali form
  inputData.value = "";
});

Praktikum

Tiga latihan ini dirancang agar kamu terbiasa menulis sintaks addEventListener. Saat menguji, mesin pemeriksa akan secara otomatis mengeklik elemenmu seolah-olah ada pengguna sungguhan.
