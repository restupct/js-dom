Manipulasi DOM • Hari 1 dari 4

Halaman bisa diubah dari JavaScript.

Sampai hari ini kodemu hanya berbicara ke console.log. Hari ini kodemu mulai berbicara ke halaman: memilih bagian tertentu, lalu mengubah isi dan tampilannya.

Tujuan pembelajaran

  1. Menjelaskan apa itu DOM dan mengapa halaman bisa berubah tanpa dimuat ulang.
  2. Memilih satu elemen dengan querySelector dan banyak elemen dengan querySelectorAll.
  3. Mengubah teks yang tampil dengan textContent.
  4. Mengubah tampilan dengan classList tanpa merusak kelas yang sudah ada.

Mengapa kita perlu DOM

Bayangkan papan progres magang yang menampilkan total jam kerjamu. Tanpa DOM, angkanya ditulis langsung di HTML — setiap kali berubah, filenya harus diedit dan halaman dimuat ulang.

Tanpa DOM

Angka ditulis tetap di HTML. Kalau totalnya berubah, kamu harus mengedit file dan menyimpan ulang. Halaman hanya bisa dibaca.

Dengan DOM

Angka dihitung oleh JavaScript lalu ditulis ke halaman saat itu juga. Data berganti, tampilan ikut berganti. Halaman jadi hidup.

Semua yang kamu pelajari sebelumnya tetap terpakai: variabel untuk menyimpan data, pengkondisian untuk memutuskan, perulangan untuk memproses banyak data. Yang baru hari ini hanyalah tujuan akhirnya — hasilnya tidak lagi dicetak ke Console, melainkan ditulis ke halaman.

Apa itu DOM

Ketika browser membaca file HTML, ia tidak menyimpannya sebagai teks. Browser membangunnya menjadi pohon objek — setiap tag menjadi satu objek yang bisa disentuh oleh JavaScript. Pohon inilah yang disebut DOM (Document Object Model).

HTML seperti ini:

<div class="kartu">
  <h2 id="nama">Rizky</h2>
  <p class="divisi">Web</p>
</div>

oleh browser dibangun menjadi pohon seperti ini:

document
└─ html
   └─ body
      └─ div.kartu
         ├─ h2#nama      → teks: "Rizky"
         └─ p.divisi     → teks: "Web"

Karena bentuknya pohon, setiap elemen punya alamat yang bisa dituju. Pekerjaan kita hari ini selalu dua langkah: pilih elemennya, lalu ubah sesuatu padanya.

Langkah 1 — Memilih elemen

Untuk memilih satu elemen, gunakan document.querySelector(). Isinya ditulis persis seperti selector CSS: pakai # untuk id, pakai . untuk class.

const nama = document.querySelector("#nama");     // id
const divisi = document.querySelector(".divisi"); // class
const judul = document.querySelector("h2");       // nama tag
Di HTMLSelectorArtinya
id="nama""#nama"satu elemen dengan id itu
class="divisi"".divisi"elemen berkelas itu
<h2>"h2"elemen dengan nama tag itu
Kesalahan nomor satu pemulaMenulis querySelector("nama") tanpa tanda pagar. Itu berarti “carikan elemen bertag <nama>”, yang tidak ada — hasilnya null.

Kalau kamu butuh banyak elemen sekaligus, pakai querySelectorAll(). Perhatikan akhiran All-nya: hasilnya kumpulan, bukan satu elemen. Kumpulan tidak bisa langsung diubah — harus dilewati satu per satu dengan perulangan.

const semuaHari = document.querySelectorAll(".hari");

semuaHari.forEach(function (hari) {
  // di sini "hari" adalah satu elemen
});

Langkah 2 — Mengubah teks dengan textContent

Setelah elemennya dipegang, isi teksnya diubah lewat textContent. Sifatnya seperti variabel: bisa dibaca, bisa ditimpa.

const nama = document.querySelector("#nama");

console.log(nama.textContent);        // membaca  → "Rizky"
nama.textContent = "Rizky Pratama";   // menimpa
Angka otomatis menjadi teksMenulis total.textContent = 34; tetap benar. Browser mengubahnya menjadi teks "34" saat ditampilkan.
Kenapa bukan innerHTML?innerHTML memperlakukan isinya sebagai kode HTML, sehingga tag di dalamnya akan dijalankan. Kalau isinya berasal dari ketikan orang lain, itu celah keamanan. Selama teks yang kamu tulis memang teks biasa, textContent selalu pilihan yang benar dan lebih aman.

Langkah 3 — Mengubah tampilan dengan classList

Warna, garis, dan ukuran sebaiknya tetap diatur di CSS. Tugas JavaScript hanya memasang dan melepas kelas, lalu CSS yang mengurus tampilannya.

PerintahFungsinya
classList.add("selesai")menambahkan kelas, kelas lain tetap aman
classList.remove("selesai")melepas satu kelas saja
classList.toggle("selesai")ada jadi hilang, hilang jadi ada
classList.contains("selesai")memeriksa, hasilnya true atau false
Jangan pakai className =Satu elemen bisa punya banyak kelas sekaligus. kartu.className = "selesai" menghapus seluruh daftar kelas dan menyisakan satu — bentuk kartunya ikut rusak. Pakai classList.add supaya yang lain tidak tersentuh.

Kapan kodemu dijalankan

Ini bagian yang sering membuat kode benar terasa salah. Browser membaca HTML berurutan dari atas ke bawah. Kalau <script> diletakkan di bagian atas, saat kodemu berjalan elemen di bawahnya belum ada. querySelector pun mengembalikan null.

Kebiasaan yang menyelesaikan hampir semua kasus ini cuma satu, dan kamu memegang kendalinya:

<body>
  ... seluruh isi halaman ...

  <script src="script.js"></script>   <!-- letakkan di sini -->
</body>

Letakkan <script> sebagai baris terakhir sebelum </body>. Dengan begitu seluruh elemen sudah dibaca browser sebelum kodemu berjalan.

Satu pola yang akan kamu lihat besokKadang kamu menemukan kode orang lain yang skripnya terpaksa berada di atas. Cara mereka menundanya seperti ini:

document.addEventListener("DOMContentLoaded", function () { ... })

Artinya sederhana: “jalankan isinya nanti, setelah halaman selesai dibaca”. Belum perlu kamu hafalkan hari ini — cukup kenali bentuknya, karena besok kamu akan bertemu kasus yang membutuhkannya.

Membaca error di Console

Bug DOM sering tidak menampilkan apa pun di halaman. Console adalah tempat pertama yang harus kamu buka — tekan F12, lalu pilih tab Console.

Kebiasaan yang menghemat banyak waktuSebelum menebak, cetak dulu: console.log(nama). Kalau yang tercetak null, masalahnya ada di tahap memilih — belum di tahap mengubah.
